# Legacy experiments

These files are the earlier generations of the boiler monitor:

- `boiler.sh` — Tesseract with cropped rows.
- `boiler-tesseract.sh` — later Tesseract variant.
- `boiler-vlm.sh` — first Ollama vision variant.
- `boiler-gemini.sh` / `gemini_boiler.py` — Google Gemini variants.

They are not maintained and are not installed by the systemd unit. They remain
here for reference.
